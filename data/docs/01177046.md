# HLS 协议简介

HLS（HTTP Live Streaming）是 Apple 开发的流媒体传输协议。

## 核心原理
- 视频文件被切割成 .ts 片段（默认每片 10 秒）
- 通过 .m3u8 索引文件描述所有片段的 URL
- 客户端按需请求片段，实现 ABR 自适应码率

## M3U8 文件示例
```
#EXTM3U
#EXT-X-VERSION:3
#EXT-X-TARGETDURATION:10
#EXTINF:10.0,
segment_0000.ts
#EXTINF:10.0,
segment_0001.ts
```

## ABR 多码率
HLS 支持多路流，客户端根据带宽自动切换：
- 高码率：1080P 8Mbps
- 中码率：720P 4Mbps  
- 低码率：480P 1.5Mbps

## GOP 与关键帧
每个 .ts 片段的起点必须是关键帧（IDR frame），
切片边界对齐 GOP，保证无缝切换。
